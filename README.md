# Athens Sublet Hub

I'm building a student sublease marketplace called LeaseUp for UGA students in Athens, GA. I have a full HTML prototype of the design — I'll paste it below as a reference. Build this as a real React + Supabase app with: real user authentication (UGA .edu email preferred), listings stored in a shared Supabase database all users can see, the ability to post and browse subleases, an in-app messaging system between users, and user profiles. Use my HTML file as the exact design reference — match the colors, layout, card style, and UI patterns as closely as possible. Brand colors: blue #2563EB, background #F0F2F5, surface white. Then paste the full HTML.
